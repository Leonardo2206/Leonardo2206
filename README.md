## 📌 Featured Projects

### 📚 [Libra](https://github.com/Leonardo2206/Libra) — Full-stack book catalog
REST API with Express 5 and PostgreSQL (Supabase) plus a React 19 frontend: public catalog and private admin panel. JWT in httpOnly cookie, versioned SQL migrations, Zod validation, cover uploads, tests with Vitest + Supertest.
`TypeScript` `Express 5` `PostgreSQL` `React 19` `Supabase`

### 🎫 [Ticket System](https://github.com/Leonardo2206/ticket-system-backend) — Support ticket management
REST API with Express 5 and MongoDB. Roles (admin, agent, user), JWT authentication, Zod validation, login rate limiting and Swagger docs. React + Tailwind frontend with protected routes.
`TypeScript` `Express 5` `MongoDB` `Mongoose` `React`

### 🏋️ [EcommerceGym](https://github.com/Leonardo2206/EcommerceGym) — E-commerce (academic project)
Catalog, cart and authentication with Next.js 15, an Express REST API, MongoDB and an admin panel. Checkout is a demo and does not process real payments.
`Next.js` `React` `Express` `MongoDB` `Tailwind CSS`
